## Objetivo

Transformar o PDV numa venda real: buscar produtos, montar o carrinho, identificar o cliente, escolher o pagamento, finalizar ou salvar orçamento e acompanhar a nota até imprimir o cupom. Os 4 botões e a busca sem handler passam a funcionar.
